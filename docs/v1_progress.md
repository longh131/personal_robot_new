## 2. 功能进度总表

### 2.1 已完成

- ROS Safety + Command Bus + C30D 限速运动链  
- 软件急停锁存、模式互斥、命令超时清零  
- 网页 REMOTE（登录、心跳、遥控、限速滑条、云台、媒体库、favicon）  
- WebRTC 对讲 + 预览/拍照/录像/录音（相机硬件正常时）  
- frpc 穿透（配置本地）  
- AWAKE：唤醒「小派」、ASR/TTS、关键词指令、LLM 闲聊  
- 天气/新闻（百炼搜索）、时间日期电量  
- 长期记忆（确认写入 / 查询 / 确认删除）  
- 倒计时 / 提醒 / 取消；听不清与超时前提示；近障语音停走  
- 语音持续行走 + 快点/慢点；退出 AWAKE 可靠回 IDLE，再登 REMOTE  
- 雷达 `/scan` + Safety 四向近障刹速  
- LED / 蜂鸣器基础线索  
- UPS 电量只读与 IDLE 低电提示
